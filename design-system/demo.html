Introduction

Welcome to the official documentation for Smart Network Mapper (SNM). SNM is a professional security suite designed to provide high-fidelity network diagnostics and automated vulnerability mapping.

Project Status

SNM is currently in version 1.0. Direct executable downloads for Windows, Linux, and Mac are under development.

Installation

To get started, clone the repository and install the necessary Python dependencies.

# Clone the repository
git clone https://github.com/Amine-NAHLI/smart-network-mapper.git

# Install dependencies
pip install -r requirements.txt

Prerequisites

Before running the tool, ensure you have Python 3.8+ and Npcap installed on Windows systems.

Administrator Privileges

Network scanning requires raw socket access. Please run the tool as an Administrator or with sudo.

Feature Overview

Feature Description Status
Auto LAN Detection Automatically detects active network interfaces. Stable
OS Fingerprinting Identifies operating systems via TTL analysis. Stable
AI Predictor Predicts CVE severity using Random Forest models. Stable
Native Binaries Stand-alone executables for all platforms. WIP

Security Warning

Only use this tool on networks you are authorized to test. Unauthorized scanning may be illegal.

Example API Response

The tool generates JSON reports with the following structure:

{
  "host": "192.168.1.1",
  "status": "online",
  "ports": [
    { "port": 80, "service": "http", "severity": 0.45 },
    { "port": 22, "service": "ssh", "severity": 0.12 }
  ]
}
